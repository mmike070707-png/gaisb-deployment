# GAISB Deployment
## About
GAISB is a truth-focused conversational interface designed for efficient information retrieval and interaction.

## Features
* **Conversational Interface**: Optimized for direct, accurate responses.
* **Backend Integration**: Utilizes a FastAPI backend with integrated API routing for seamless performance.

## How to use
This application is deployed via Vercel. You can interact with the system via the provided interface or by sending requests to the `/api/` endpoints.

## Status
* **Deployment**: Active
* **Framework**: React / TanStack Start
